### 朝向（闸门 0 必查项 · 只判一次）

**结论（一句话）**：**横版（Landscape）** + 画布参考分辨率 **1920×1080**（16:9） + **需按竖版重排的面板 = 无**。

> 判据优先级（SKILL §6 闸门 0）：① 原版这款游戏的**原生朝向** → ② 用户本轮是否明说 → ③ 都没有则按原版。
> 本轮用户**未**提朝向 ⇒ 按原版 = 横版（⛔ 不是"没查就默认横屏"：四条必查项逐条实测见下表）。

| 必查项 | 判定 / 实测值 | 出处 |
|---|---|---|
| **① 原版 D2 原生朝向** | **横版**（宽 > 高） | 官方菜单屏贴图实测（下一行）；素材即 A 本体，见 `策划/素材调研.md` §4 |
| ①-a 铁证（原版素材实测） | `main_screen.png` / `class_select_screen.png` / `load_screen.png` / `multi_player_screen.png` 实测均 **800 × 600**（宽>高 = 横版） | `client/Assets/Resources/Clover/D2/UI/Menu/*.png`（`System.Drawing` 读 PNG IHDR） |
| ①-b 联网检索 | Bing 可达但命中结果为公司/商店页，**未命中朝向陈述**；Wikipedia / PCGamingWiki / Fandom / DuckDuckGo 本机 **HTTP 000（不可达）** ⇒ 以 ①-a 原版素材实测为铁证 | 本轮抓取（临时文件在 `.ai-tmp/test/`，用完即删） |
| **② ProjectSettings.asset** | `defaultScreenOrientation: 4` = **`UIOrientation.AutoRotation`**（"默认移动设备朝向"，开启自动旋转；**桌面独立构建不生效**）；`defaultScreenWidth: 1920` / `defaultScreenHeight: 1080`（16:9 横）；`fullscreenMode: 1` | `client/ProjectSettings/ProjectSettings.asset:11 / :44 / :45 / :116`；枚举出处 `UnityCsReference/Editor/Mono/PlayerSettings.bindings.cs`（`UIOrientation`：Portrait=0 / PortraitUpsideDown=1 / LandscapeRight=2 / LandscapeLeft=3 / **AutoRotation=4**；`defaultScreenOrientation` ↔ `[NativeProperty("DefaultScreenOrientation")] defaultInterfaceOrientation`），本机 Unity 6 程序集含 `get_defaultInterfaceOrientation` 佐证 |
| **③ 引擎参考分辨率** | **1920 × 1080**（引擎默认 = 横版；本项目**未覆盖**：全仓无 `CloverPresentation.ReferenceResolution` 赋值） | `clover-client-unity-engine/Runtime/Presentation/CloverPresentation.cs:85`（`= new Vector2(1920f, 1080f)`）；`Runtime/Presentation/UI.cs:59`（`scaler.referenceResolution = CloverPresentation.ReferenceResolution`） |
| **④ 面板布局常量与朝向自洽** | **自洽（无冲突）**：全项目按 1920×1080 横版布点 —— 流程面板 `RefWidth=1920 / RefHeight=1080`；游戏内面板 `K=1.8`（原版 800×600 → ×1.8 居中）。**存在多处 ≥1200 的横排布局，且它们只在横版下成立**（竖版画布宽 ~1080 会挤爆）：角色选择列表 `ListSize = 1285.2×580.5`、启动屏两条 `1260×36` / `1260×72`；原版 HUD `ControlPanel.png` 948×160 → ×1.8 = **1706.4** 画布宽（占 1920 的 89%）。 | `client/Assets/Scripts/UI/UiLayoutFlow.cs:142,145,154,924,1653,1657`；`client/Assets/Scripts/UI/UiLayoutGame.cs:63`；`client/Assets/Scripts/UI/BootPanel.cs:60,62`；`client/Assets/Scripts/Core/GameConst.cs:237,240` |

> **落地口径**：竖版专用规则（上下排布 + 角锚点、⛔ 不靠 `preserveAspect` 留左右黑边）**本项目不适用** —— 本项目为横版，**无需任何面板按竖版重排**。

> ✅ **已收口（2026-09-21 主 agent）**：`## 1. 保真目标` 表内「分辨率」一行已更正为「逻辑 **1920×1080**」（出处：`client/ProjectSettings/ProjectSettings.asset:44-45` + `clover-client-unity-engine/Runtime/Presentation/CloverPresentation.cs:85` + `client/Assets/Scripts/Core/GameConst.cs:237,240`），与实测画布参考分辨率一致。原「逻辑 1280×720」是**历史错值**（全仓代码从未按它实现 —— `Core/GameConst.cs:230-240` 明确写「项目侧若按 1280×720 布点，所有面板在真机上整体放大 1.5 倍并错位 ⇒ 一律按 1920×1080 写布局」）。

## 7. 架构与分层（强制，见 `reference/architecture.md`）

```
client/Assets/Scripts/
├── Def/          MsgDef（本项目不用消息号，保留占位）/ 枚举 / 纯数据定义（无 Unity 依赖）
├── Core/         GameConst / SceneNames / Events / ResPaths / Cfg(ClientConfig) / 等距数学 / 随机
├── Module/
│   ├── Flow/       AppFlow：启动→主菜单→选角→创角→读条→进图→暂停→回菜单
│   ├── Map/        MapModule：格子地图、随机生成、可走查询、A*、等距投影与渲染
│   ├── Player/     PlayerModule：点击移动、本地解算、属性、装备生效
│   ├── Combat/     CombatModule：伤害/命中/抗性/死亡/复活/掉落
│   ├── Monster/    MonsterModule：AI（追击/逃跑/复活同伴/远程）、精英词缀
│   ├── Quest/      QuestModule：任务状态机（邪恶洞穴）
│   ├── Npc/        NpcModule：NPC 定义、对话、商店、修理
│   ├── Item/       ItemModule：物品生成（词缀/品质）、背包、装备、腰带
│   ├── Skill/      SkillModule：技能树、学习、施放、投射物
│   ├── Input/      InputModule：鼠标点击/悬停拾取、快捷键
│   ├── Camera/     CameraModule：等距跟随相机
│   ├── View/       ViewModule：精灵实体视图（行走朝向、动画、血条、飘字）
│   ├── Audio/      AudioModule：音效触发点（脚步/挥砍/命中/UI/环境）
│   └── Save/       SaveModule：存档读写（Game.Setting）
├── UI/           面板（Boot/MainMenu/CharSelect/CharCreate/Loading/Hud/Inventory/
│                      Character/技能树/Quest/NpcDialog/Shop/Pause/Settings/死亡提示）
└── App/          Bootstrap（唯一手动挂载，≤200 行）
client/Assets/Editor/
├── ProjectBuilder.cs     一键生成：场景 / 预制体（Resources/UI/*）/ AnimatorController / BuildSettings
└── AssetImporter.cs      原版贴图导入设置（Point 过滤、无压缩、轴心、九宫格）
```

- **依赖单向**：`App → Module → Core → Def`；`UI` 只许 `Core/Def` + 事件总线；
- **跨模块协作只走事件或 App 注入的接口**；`App/Bootstrap.cs ≤ 200 行`；
- 事件名集中在 `Core/Events.cs`，资源路径集中在 `Core/ResPaths.cs`（**换素材不动逻辑**）。

## 8. 本项目与全局 skill 的差异（**写清以便后续 AI 不去"纠正"**）

| 项 | 全局 skill 通用写法 | 本项目 | 原因 |
|---|---|---|---|
| 视角/操作 | 有角色就做第三人称相机 + 方向键移动 + 鼠标转视角 | **固定等距 + 鼠标点击移动**（**没有**方向键备选移动 —— 片 8 已把曾经多余的备选输入整体删除） | **参考游戏保真优先**：原版 D2 就是等距点击移动（原版没有的输入路径 ⇒ 不加） |
| 服务器 | 默认按联服处理 | **完全没有**（单机） | 见 §0 形态判定 |
| 地图 | 用引擎 `MapBake` + `Game.Map`（烘焙静态地图） | **业务侧程序化格子地图 + A\*** | 原版野外与地牢是**每局随机生成**，而 `MapBake` 产出的是**静态**烘焙地图，语义不符；引擎的 CloverMap 写入器为 `internal`，业务无法在运行时构造。**未重造任何二进制格式**（不解析/不生成 CloverMap） |
| 消息号 | 业务消息号 ≥ 10001 | **不用消息号**（单机无网络） | 同上 |
| 配表 | `_c/_s/_cs` 三后缀 | 全 `_c`（单机） | 打表只出客户端产物 |
