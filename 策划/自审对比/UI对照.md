# UI 对照 —— **任务日志面板（Q）× NPC 对话面板** vs 原版《暗黑破坏神 II》

> 用户原话（经主 agent 转述）：**「任务框 ui 都不对」**。
> 上一轮（a50）把两个面板的代码改了，但**取证/文档/清场三件事没做完**（没有 `UI对照.md`、
> 证据图落在 `client/Screenshots/`、`.ai-tmp/test/` 堆了 282 个一次性文件）。
> **本轮（a51）= 补齐这三件事 + 按实机读图结果再修一遍版面**，口径与判定逐条写在下面。

**判定口径**：每项只写 `一致` 或 `不一致（差在哪）`；**出现"不一致"⇒ 该版本不可交付**。
凡**原版素材/参考工程里确实没有坐标出处**的项，写 `一致（推导）` 并登记 E 编号（⑥ 有全表），
**不许拿"看起来差不多"当 `一致`**。
