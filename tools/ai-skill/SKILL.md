本项目：**用 Clover 引擎复刻《暗黑破坏神 II》Act I 起始两张地图（罗格营地 / 血腥荒野）+ 任务地牢「邪恶洞穴」+ 主线任务 1（Den of Evil）**。
**单机版**（不接服务端、不调 `CloverNet.Init`、不查服务器环境）。

跑法：用 Unity Hub 打开 `client/`（Unity 6000.6.0f1），进 `Boot` 场景 Play。
生成工程资产：菜单 `Diablo2 → 一键生成工程（场景 + 预制体 + BuildSettings）`。

## 四条硬规则

1. **新设施先登记再写代码**：新增模块 / 面板 / 场景 / 事件 / 资源路径 / 配表 → **同步更新 `registry.md`**。
2. **只记本项目特有的东西**，通用规则**不许**抄进来（抄了必然两边漂移）。
3. **契约冻结**：`docs/步骤文档.md` §2/§3 的配表列名、引擎 API 签名、常量与 `ResPaths`、场景与面板名
   —— **不许私自改**；发现问题先回报主 agent。
4. **子 agent 不会自动继承 skill**：派子 agent 时，任务书里必须写明「怎么拿到本 skill」。

## 本项目最容易踩的五件事（先看这个）

| 坑 | 一句话 | 详见 |
| --- | --- | --- |
| **一个 `.cs` 里放多个 MonoBehaviour** | 预制体 `m_Script` 指向错 fileID，运行时面板打不开且编译不报错 | `constraints.md` #1 |
| **`timeScale = 0` 用 `After/Every`** | 暂停/结算屏定时器永不触发（零报错） | `constraints.md` #2 |
| **`Image.Type=Filled` 但没 sprite** | 血球/经验条 `fillAmount` 静默失效 | `constraints.md` #3 |
| **鼠标点击移动的"自己的位置"** | 等距反投影 + 本地解算；不许被任何权威位置逐帧覆盖 | `conventions.md` §坐标 |
| **单机不许碰网络门面** | `Game.Net/Sync/Alert/Http/...` 一律为 null，调用必崩 | `conventions.md` §形态 |
