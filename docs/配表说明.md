## 1. 五步闭环与命令（改数值只走这五步，不要手改产物）

```powershell
$P = "clover-project-diablo2"

# ① 官方 txt → 源表 策划/数值文档/*_c.txt（11 张，UTF-8 无 BOM、tab 分隔、4 行表头）
python "$P\tools\table-convert\convert.py"

# ② 源表 → xlsx（给策划用 Excel 编辑；默认不覆盖已存在的 xlsx，需覆盖加 -force）
cd "clover-tools\table\core"
go run ./cmd/table -pack -config "$P\tools\table\config.yaml" -batch

# ③ xlsx → tsv + C# 强类型代码
go run ./cmd/table -config "$P\tools\table\config.yaml" -batch

# ④ tsv → 运行时目录（StreamingAssets，见 §3）
python "$P\tools\table-convert\sync_tsv.py"

# ⑤ 编译自检（打表产物本身是 Unity 无关的纯 C#，可独立 dotnet build）
dotnet build "$P\_table_discard\verify\TableVerify.csproj" -v q --nologo
```

`convert.py` 的 `--report` 只统计不写文件、`--names` 打印中文映射审计清单；
`sync_tsv.py` 的 `--check` 只比对不拷贝（不一致时退出码 1）。

## 3. 运行时怎么读配表（**后续 agent 照这一段写，不要另造轮子**）

### 3.1 结论（先去读源码、不是猜的）

| 问题 | 结论 | 出处 |
|---|---|---|
| 生成的表怎么读数据？ | `File.ReadAllLines(path)` 读**真实文件系统路径**下的 tsv | `clover-tools/table/core/internal/gen/cs.go:279`（`csBaseTable` 模板里的 `Load`） |
| 要放 `Resources` 下吗？ | **不要**。`Resources.Load` 拿到的是内存资产、没有文件路径；且 `.tsv` 不是 Unity 的 TextAsset 扩展名 ⇒ 放 `Resources/` 下**读不到** | 同上（`Load` 只吃 path，没有 `LoadFromText`） |
| 要调 `CloverData.InitDataTable(dir)` 吗？ | **不要**。那是引擎自带的**另一条**通用 TSV 链路，要求行类实现 `IDataRow`（`int Id`）；打表生成的行类（`Base*Row`）**不实现** `IDataRow` | `Runtime/Data/DataTable.cs:33`、`Runtime/Data/CloverData.cs:16`、`Runtime/Core/Contracts.cs:911`、`gen/cs.go:252`（行类只有 public 字段） |
| tsv 放哪？ | `client/Assets/StreamingAssets/Table/*.tsv` —— 编辑器与 Windows 独立版下 `Application.streamingAssetsPath` 都是**真实目录**；`Assets/StreamingAssets/**` 会原样进包（不受导入设置影响） | `tools/table-convert/sync_tsv.py`（打表后必跑） |

打表把 tsv 写到 `<client_dir>/Tsv/`（`clover-tools/table/core/internal/gen/cs.go:96` 写 tsv、
`internal/config/config.go:151` 定 `ClientDir/Tsv` 这个目录名），所以才有第 ④ 步「同步到 StreamingAssets」。

### 3.2 唯一的调用形态（可直接粘）

```csharp
// 放进 Bootstrap（App/Bootstrap.cs），Game.Launch 之后调用一次即可
string err = Table.TableLoader.LoadAll(
    UnityEngine.Application.streamingAssetsPath,   // 发布后：<build>_Data/StreamingAssets/Table
    UnityEngine.Application.dataPath);              // 编辑器回退：<project>/Assets/Scripts/Table/Tsv
if (err != null) Game.Logger.Error("Table", err);
else             Game.Logger.Info("Table", "配表已加载：" + Table.TableLoader.LastDir);
```

`TableLoader.LoadAll` 成功返回 `null`、失败返回**可定位的错误串**（缺哪个文件都报出来），
日志由调用方用 `Game.Logger` 打（不在 Table 目录里裸 `Debug.Log`）。
**这一行的落点（`App/Bootstrap.cs`）属工程骨架/流程模块，本 agent 不碰。**

### 3.3 `Tables.Default.<表>.Get(主键)` 的确切签名（从生成的 Registry.cs 抄的）

```csharp
namespace Table {
  public class Tables {
    public static Tables Default = new Tables();
    public AffixTable        Affix        = new AffixTable();        // Get(int)
    public ClassTable        Class        = new ClassTable();        // Get(int) → BaseClassRow
    public ExperienceTable   Experience   = new ExperienceTable();   // Get(int) → BaseExperienceRow
    public ItemTable         Item         = new ItemTable();         // Get(int)
    public LevelTable        Level        = new LevelTable();        // Get(int)
    public MissileTable      Missile      = new MissileTable();      // Get(int)
    public MonsterTable      Monster      = new MonsterTable();      // Get(int)
    public MonumodTable      Monumod      = new MonumodTable();      // Get(int)
    public SkillTable        Skill        = new SkillTable();        // Get(int)
    public TreasureclassTable Treasureclass = new TreasureclassTable(); // Get(string) ← 唯一 string 主键
    public void LoadAll(string dir);       // dir/<名字>.tsv，逐个 LoadWithHooks
  }
}
```


## 4. 数值换算公式与出处（**改公式前先看这里**）

| 表/列 | 公式 | 出处/说明 |
|---|---|---|
| `class_c.life_per_lvl` / `mana_per_lvl` / `stam_per_lvl` / `life_per_vit` / `mana_per_mag` / `stam_per_vit` | 官方值 **÷4** | `charstats.txt` 的 `Comment` 列原文 = "The following are in fourths"（1/4 单位） |
| `monster_c.hp_min/hp_max` | `官方 minHP/maxHP × MonLvl.HP / 100` | `MonStats.txt` 的 hp 是**基值**，需按区域等级到 `MonLvl.txt` 取倍率（普通难度列） |
| `monster_c.hp` | `(官方 minHP + maxHP)/2 × MonLvl.HP / 100` | 同上 |
| `monster_c.ac` / `ar` / `dmg_min` / `dmg_max` / `exp` | `官方 AC/A1TH/A1MinD/A1MaxD/Exp × MonLvl.{AC,TH,DM,DM,XP} / 100` | 同上 |
| 怪物换算所用等级 | **1**（`level_c.area_level`：血腥荒野 1 / 邪恶洞穴 1 / 罗格营地 0 且无怪） | `Levels.txt` 的 `MonLvl1`；官方 `MonStats.Level` 另存 `base_level` 列，不做静默丢弃 |
| `skill_c.dmg_min/dmg_max` | `(MinDam + EMin) × 2^HitShift / 256` | `skills.txt` 的伤害按 `HitShift` 移位换算。例：火弹 `EMin=6 EMax=12 HitShift=7` ⇒ **3-6**（与原版一致）。⚠️ 这两列是**技能 1 级**的伤害（`staged(1) = base`），**不是**"每级伤害" —— 等级缩放见下一行 |
| `skill_c.*_lev1..5` | **官方原值，不换算** | 段位：`lev1` = 1~8 级每级增量、`lev2` = 9~16、`lev3` = 17~22、`lev4` = 23~28、`lev5` = 29+。运行时的等级缩放 = 官方 `staged`：物理与元素**各自** `(base + 各段增量) << HitShift >> 8`（**整数截断**）再相加 —— 实现见 `DamageFormula.SkillDamageRange` 与 `Staged`，出处 `libd2/packages/game/src/spell.zig:88-116` |
| `skill_c.phys_min/max` `elem_min/max` `hit_shift` | 官方原值，不换算 | 审计/公式复算用 |
| `item_c.dmg_min/dmg_max` | 官方 `mindam/maxdam`；**为空时回退到 `2handmindam/2handmaxdam`**（★ 片 14：双手武器（弓/弩/双手斧）旧实现直接读 min/max ⇒ 全是 **0**，即"拿弓打不出伤害"） | `Weapons.txt`（`dmg2_min/dmg2_max` 仍另存双手值） |
| `item_c.str_bonus` / `dex_bonus` | 官方原值 | `Weapons.txt` 的 `StrBonus`/`DexBonus`（★ 片 14 消除 E25）。运行时用法见 `DamageFormula.PhysicalDamage`：`dmg% = 力×StrBonus/100 + 敏×DexBonus/100 + 技能ED%`（**各项分别截断**），出处 `DAMAGE_CalculatePhysicalDamage @0057b420` / `libd2/.../combat.zig:149-180` |
| `monumod_c.hp_mul` / `dmg_mul` | `1 + 官方常数 hp%/100` / `1 + 官方常数 dmg%/100` | 官方常数来自 `MonUMod.txt` 的 `constants` + `*constant desc` 两列，按 desc 文本**程序化匹配**：champion chance=20%、champion +hp%=200(+tohit 75,+dmg 100)、unique +hp%=300(+tohit 100,+dmg(strong) 150) |
| 取整 | **四舍五入**（`convert.py` 的 `rnd()`） | ⚠️ 原版引擎走整数截断；截断会把等级 1 的 6% 护甲倍率抹成 0（血鹰 AC 0.84→0）。本项目改四舍五入并在此登记 |

## 5. 待补项 / 未导入的行与原因

| # | 项 | 原因 | 处置 |
|---|---|---|---|
| 1 | **中文显示名需与官方 localized `.tbl` 复核** | 官方 1.10f txt 只有英文名；`cn_names.py` 里的中文是本项目编写的 | `.tbl`（`expansionstring.tbl`/`string.tbl`/`patchstring.tbl`）到位后逐条复核，清单唯一来源 = `tools/table-convert/cn_names.py` |
| 2 | `affix_c.name` = **官方英文名**（如 `Sturdy`/`of Health`），中文在 `name_cn`（按 `mod` 码 + 数值生成的说明，如 `防御强化 20~30`） | 词缀官方名是「前缀词/后缀词」，逐条手写 301 个中文名不划算且易错 | 若需原版中文词缀名（如「坚固的」），等 `.tbl` 到位后按 `mod`+数值区间补映射 |
| 3 | `monumod_c.ac_mul = 1.0`、`res_* = 0` | **官方 `MonUMod.txt` 没有定义护甲倍率 / 抗性加成常数**（原版引擎里硬编码）⇒ 官方表里抽不到，非手抄值，是**占位** | 需要精确值时只能查原版引擎反汇编；当前占位已写进列注释 |
| 4 | `monumod_c` 未导入 `poisonhit`(id 23，官方无 `cpick/upick` 权重)、`thief`(id 24，官方 `enabled=0`)、以及 25 个非冠军/精英的辅助词缀（`none` `rndname` `hpmultiply` … `lightningdeath`） | 按「`enabled=1` 且（`champion=1` 或有权重）」过滤；辅助词缀不是"精英怪词缀" | 需要时放宽过滤即可（`convert.py` 里 `build_monumod` 的 `picks` 判定） |
| 5 | `skill_c` 的 `Poison Javelin` 官方 `HitShift` 为空 ⇒ `dmg_min/dmg_max` 为 0 | 官方毒系技能不走 `HitShift` 移位（毒素伤害依赖 `ELen/ELenSymPerCalc`，本项目暂未实现毒素持续伤害） | 原始值保留在 `elem_min/elem_max`；实现毒素 DOT 时补 |
| 6 | `item_c` 未导入官方 12 行 `name='Not used'` 杂物（`hrt/brz/jaw/eyz/hrn/tal/flg/fng/qll/sol/scz/spe`） | 官方表里就是未启用的占位行 | 无 |
| 7 | `item_c` 未导入非凡/精英（exceptional/elite）物品 | 约束「只保留 Act I 起始区域用到的行」；精英物品在噩梦+ 才掉 | 做噩梦难度时按 `code != normcode` 增量导入 |
| 8 | `missile_c` 的 `dmg_min/dmg_max/e_min/e_max` 多为 0 | 官方 `Missiles.txt` 里这些列**本来就是空的**，投射物伤害落在**技能**上（`skills.EMin/EMax`） | `used_by` 列记录了引用来源；读伤害请读 `skill_c` |
| 9 | `treasureclass_c` 只含普通难度 | 单机复刻只做普通难度 | 噩梦/地狱按 `(N)/(H)` 增量导入 |
| 10 | 契约 §2 `monster_c` 描述的「血鹰」= 官方 `foulcrow2`(`NameStr=BloodHawk`)，**不是** Act II 的 `vulture2` | 官方表里没有叫 "Blood Hawk" 的 Act I 独立怪物行，只有 `foulcrow1..4` 家族（`foulcrow2` 的 `NameStr` 就是 `BloodHawk`） | 已按 `foulcrow2` 导入；若主 agent 认为该改契约请裁决 |
