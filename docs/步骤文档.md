# clover-project-diablo2 · 项目总纲

> 本文件是项目的**大方向与介绍**：做什么、不做什么、按什么基线做、遵守哪些硬约定。
> 契约与实现细节在各处源码注释里；数值口径见 `docs/配表说明.md`；交付合同见 `策划/验收表.md`。

---

## 1. 目标

用 **Clover 客户端引擎**复刻《暗黑破坏神 II》Act I 起始两张地图（**罗格营地 → 血腥荒野**），
交付「原版级完整成品」：启动 / 菜单 / 创角链路 + 两处场景完整内容 + 游戏内流程，
画面 / 操作 / 动画 / 音效 / UI 按原版对齐。

**形态**：单机（不建 `server/`、不调 `CloverNet.Init`、不查服务器环境）。
**范围外**（明确不做）：任务系统、邪恶洞穴、Act II~V、雇佣兵、符文之语、赫拉迪克方块、
赌博深度、专家模式、Battle.net 联机、Cow Level。

## 5. 硬约定

1. **资源路径集中**：全部资源路径收敛到 `Core/ResPaths.cs`，换素材不动逻辑；运行时只走 `Tables.Default.<表>.Get(主键)`。
2. **事件名唯一来源**：`Core/Events.cs` 的常量，⛔ 禁止裸字符串事件名；业务前缀统一 `D2.`。
3. **数值一律走配表**，⛔ 禁止硬编码；写不出出处的量不进工程。
4. **引擎能力优先**：UI / 对象池 / 存档·设置 / 图集 / 本地化 / 配表 / 动画 / 相机 / 场景 / 音效一律用引擎件，⛔ 不重造轮子。
5. **资源只在项目内复制被引用的那几个**（路径经 `ResPaths`），测试产物、探针与临时件只放 `.ai-tmp/`。
6. **面板 = 一个类一个文件**，预制体名必须等于类名（`Resources/UI/{类名}`）。
7. **契约口径备忘**：
   - `Def.AreaId` **0 基**（Town=0 / BloodMoor=1），`level_c.id` **1 基** ⇒ 跨表一律经 `AreaLevelTable.Resolve`。
   - `IItemModule.DropLoot(int treasureClassId, …)` 的 int = `Treasureclass.All()` 的 **1 基行序**（0 / 越界 = 无效）。
   - 事件打包：`UnequipRequest` = `((int)ItemSlot & 0xFF) | (slotIndex << 8)`；`MoveInInventoryRequest` = `fromAnchor | (toAnchor << 16)`。
   - `D2.Player.Revived` 的发送方 = `CombatModule.RevivePlayer`（复活成功分支内发，`DeathPanel` 靠它关闭）。
   - `AppWiring` 对 `AttachRoot(Transform)` 走**反射**（不写 `is MapModule`）：App 层不产生对 `Module/Map`、`Module/View` 的编译期依赖。
