**用 Clover 引擎复刻《暗黑破坏神 II》Act I 起始两张地图（罗格营地 → 血腥荒野，含任务地牢「邪恶洞穴」）与其主线任务 1（Den of Evil），

**验收标准（可执行）**：`策划/验收表.md` **42 行全部填满、结论列无"未验/待验"**；连续两次进 Play 均通过；
每格 ≥2 条独立证据（日志行 + 截图），截图**自己读图**核对；`策划/自审对比/` 里与 A 的对照项**全部"一致"**。

- 形态：**单机**（不建 `server/`、不调 `CloverNet.Init`、不查服务器环境）
- 工程根：`clover-project-diablo2`
- 客户端工程：`<工程根>/client`（Unity 6000.6.0f1，模板 `com.unity.template.universal-2d`）

### 3.4 已核对的坑（**不许踩第二次**）

| 坑 | 结论 |
|---|---|
| `UIPanel.OnOpen` 之前拿不到 param | 状态值**只能**在 `OnOpen(param)` 里刷；漏传参要 `Warn` |
| 面板打不开 | 预制体必须叫 `Resources/UI/{类名}`（`UI.cs:104-113`）；缺失只打 Error 后 return |
| `timeScale = 0` 时 `After/Every` 永不触发 | 暂停/结算屏一律 `AfterUnscaled/EveryUnscaled` |
| 面板根节点没铺满 | 一律 `UIFactory.Stretch(rt)`；位置写成"相对父层中心的偏移" |
| `Image.Type=Filled` + 无 sprite ⇒ `fillAmount` 静默失效 | 血球/经验条改用**锚点宽度**或给 1×1 白 sprite |
| 占位体/血条 Quad 必须去掉 Collider | 否则相机探针打到自身（`Entity.cs:289`、`UIWidgets.cs:1089`） |
| 直连 `Keyboard.current` 在旧输入后端为 null | 一律 `Game.Input`；`CloverInput.Init()` 必须在建 UI 之前 |
| 一个 `.cs` 放多个 MonoBehaviour | 预制体 `m_Script` 会指向错 fileID ⇒ 运行时面板打不开且编译不报错。**一个类一个文件** |
| `AnimatorController` 只能 Editor 侧生成 | `using UnityEditor.Animations`；生成脚本放 `Assets/Editor/` |
| `Game.Res` 没 Init | `CloverRes.Init(root)` 必调，否则模型/贴图静默加载失败 |
| 业务事件别蹭 `Net.` / `App.` 前缀 | 撞引擎事件名（`Contracts.cs:363`）；本项目统一 `D2.` 前缀 |
